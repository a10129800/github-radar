❓ 小白常見問題 (FAQ)

第一次玩開源專案？大家最常問的 3 個問題這裡都有解答

⚠️ Q1：如果畫面出現「速率限制告警 (Rate Limit)」該怎麼辦？
原因：GitHub 官方為了防範機器人洗版，規定「未登入訪客每分鐘最多查詢 10 次」。
解法：① 只要稍等 1~2 分鐘就會自動恢復。② 或者在專案目錄下建一個 .env 檔案填入免費 GitHub Token（參考 .env.example），每分鐘額度立刻暴增到 30 次以上！
📥 Q2：我在報告裡看到滿意的神器，該怎麼下載到自己電腦？
雷達每次在詳細剖析專案（--info）的最後，都會貼心附上一行下載代碼，例如：
git clone --depth 1 https://github.com/作者/專案.git
只要複製這一行貼到終端機按 Enter，幾秒鐘就能把專案乾淨下載到電腦裡！
🤖 Q3：這個雷達需要每次打開終端機都重新安裝一次嗎？
完全不需要！ 只要第一次執行過 .\install.ps1，雷達技能就已經自動常駐在你的全域 AI 設定庫中。以後無論在任何資料夾開啟 AI，直接跟 AI 說人話，AI 就會隨傳隨到幫你掏金！
